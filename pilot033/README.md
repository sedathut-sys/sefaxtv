# 0.33 — Yerel gerçek canlı dublaj kullanıcı prototipi
0.32: HLS parser PASS, Alabama manifest HTTP 404; model kurulumu ve canlı dublaj çalışmadı (45886717311). Yeni doğrulanmış sabit İngilizce HLS adresi bulunamadı; rastgele IPTV veya erişim engeli aşma yok. Kanal yerine tekrar kullanılabilir yerel oynatıcı geliştirildi. Model yığını 0.30, VAD 0.32; tek işçi + 1 bekleyen iş, 8 yeni canlı parça, alım sonrası 5 sn hesap/teknik kontrol tamponu, orijinal ses fallback. Kullanıcıya gerçek oynatma ancak izinli HTTPS TS/H264/AAC kaynağı varsa mümkündür. Şifre, token, query, yönlendirme, farklı origin, VOD, LL-HLS, fMP4 ve alternatif ses reddedilir. IP DNS kontrolü basit korumadır; DNS rebinding'e karşı tam ağ izolasyonu değildir, yalnız yerel CLI'dan kullanılır. Yayıncı sayfası CLI kaydı ve kullanıcı onayı kaynak yetkisinin beyanıdır; program hakları doğrulamaz. Sadece 127.0.0.1, rastgele oturum yolu ve aynı-origin durdurma, geçici dosyalar, harici medya export yok. Windows/Linux: Python 3.11, FFmpeg/ffprobe PATH, paket çıkarıldıktan sonra kök dizinden `python -m venv .venv`, ortamı etkinleştir, `python -m pip install --index-url https://download.pytorch.org/whl/cpu torch==2.6.0`, `python -m pip install -r pilot030/requirements.txt`. Sonra `python pilot033/start.py --source "YAYINCININ_IZINLI_HTTPS_M3U8_ADRESI" --publisher-page "RESMI_HTTPS_SAYFA" --confirm-permitted-source`. Bu örnek değerler gerçek adres değildir. Tarayıcı yerel sayfayı açar; ilk model yüklemesi internet gerektirir. Çalışma kodu ve gerçek kaynak henüz kullanıcı cihazında test edilmedi. Paket oluşturma CI hedefli tests: origin, deadline, playlist, local server.
